HTML: Resumão

Uma retrospectiva completa dos módulos de HTML (Aulas 06, 08 e 24).

1. A Fundação (Tags Básicas)

⚡ Dica de Produtividade (VS Code)

Não precisa decorar a estrutura inicial! No VS Code, digite ! (ponto de exclamação) e aperte Enter.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Document</title> </head> <body> </body> </html>

Tags de Texto e Estrutura

  • h1 a h6: Títulos (Importante para SEO).
  • p: Parágrafos.
  • span: Texto genérico inline (para estilizar pedaços).
  • strong: Texto em negrito (importância).
  • em: Texto em itálico (ênfase).
  • br: Quebra de linha (Break Row).
  • hr: Linha horizontal (Horizontal Rule).

Listas e Links

  • ul: Lista não ordenada (bolinhas).
  • ol: Lista ordenada (1, 2, 3).
  • li: Item da lista (List Item).
  • a: Links (Âncora). O atributo href define o destino.
  • img: Imagens. src é o caminho, alt é a descrição.

2. HTML Semântico (Significado)

Não usamos apenas div. Usamos tags que explicam o que é o conteúdo para o navegador e leitores de tela (SEO e Acessibilidade).

  • <header>: Cabeçalho da página ou seção.
  • <nav>: Links de navegação principais.
  • <main>: O conteúdo principal e único da página.
  • <section>: Uma seção temática do conteúdo.
  • <article>: Conteúdo independente (ex: post de blog, card de produto).
  • <aside>: Conteúdo lateral (barra lateral, banners).
  • <footer>: Rodapé (copyright, contatos).

3. Interação e Dados (Forms e Tabelas)

Vimos como coletar dados do usuário e exibir dados estruturados.

Formulários Modernos

O uso correto de type e validações nativas.

<form> <label for="email">E-mail:</label> <input type="email" id="email" required placeholder="seu@email.com"> <label for="senha">Senha:</label> <input type="password" id="senha" required minlength="6"> <button type="submit">Entrar</button> </form>

Tabelas (Apenas para Dados)

<table> <thead> <tr> <th>Nome</th> <th>Idade</th> </tr> </thead> <tbody> <tr> <td>Ana</td> <td>25</td> </tr> </tbody> </table>

4. Conteúdo Externo (iFrames)

Aprendemos a abrir "janelas" para outros sites dentro do nosso, útil para vídeos e mapas.

<!-- Exemplo de Youtube Embed --> <iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allowfullscreen> </iframe>

Lembrando das restrições de segurança (X-Frame-Options) que impedem alguns sites de serem embutidos.
